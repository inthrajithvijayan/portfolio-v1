# Inthrajith — Portfolio

## Setup

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:5173`).

## Notes

- Update the email address in `src/sections/Contact.jsx` (`hello@example.com`).
- Update social links in `src/sections/Hero.jsx` and `src/sections/Contact.jsx`.

## Tech

- React + Vite
- Tailwind CSS
- Framer Motion (scroll + hover animations)
- GSAP (interactive 3D tilt)
- Three.js via `@react-three/fiber` (Hero starfield)
- Lenis (smooth scrolling)
